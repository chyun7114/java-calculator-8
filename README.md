# java-calculator-precourse

---
### 기능 요구사항
- [ ] 문자열 분리
  - [x] 쉼표(,) 또는 콜론(:)을 기준으로 문자열 분리
  - [x] "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용시 문자열 분리.
- [ ] 값 계산
  - [ ] 분리된 숫자 값의 합을 반환
- [ ] 컨트롤러 구현
  - [ ] 유저 입력 콘솔 구현
  - [ ] 콘솔 출력 구현
- [ ] 예외 처리
  - [ ] 잘못된 값을 입력하는 경우 `IllegalArgumentException` 반환 후 애플라케이션 종료
    - [ ] 잘못된 구분자를 입력된 경우 (문자열 분리가 제대로 이뤄지지 않은 경우)
    - [ ] 양수가 아닌 문자를 입력하는 경우
